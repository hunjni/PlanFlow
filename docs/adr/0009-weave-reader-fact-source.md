# weave 阅读器桥接联动：阅读书籍模式的完成事实源

阅读书籍模式建目标一直靠手填层级/粘贴目录，且阅读与勾选两张皮——读完不打勾，进度失真。用户自用 fork weave epub reader（非市场插件，源码在手），决定**桥接互操作**：fork 暴露 public 桥 API（书架 / 目录 / 打开章节 / 位置推进事件），planflow 经 `app.plugins.getPlugin` 消费。与 ADR-0007 方向相反：BZG 域冻结只能只读文件，weave fork 源码在手，桥是正道（Dataview/Templater 惯例；fork 自己也如此调 BZG 的 `knowledge.openTermNote`）。同时为阅读书籍模式引入**第二外部事实源**：阅读位置推进 = 看完的候选事实，经确认门落勾——BZG 事实是文件事实，这里是阅读行为事实，两者同构（事实在对方，写回在我方）。

## Considered Options

- PlanFlow 自解析 epub（读 vault 内 weave-data.json 书架 + 按 `vaultPath` 解析 ncx/nav）——fork 零改动，但把 foliate-js 已解决的问题重做一遍（.azw3/.mobi 不通），PlanFlow 永久背 zip/xml 解析依赖
- fork 暴露桥 API（**采纳**）——复用现成解析器与进度管道，个人集成下桥的跟随维护成本可接受
- 推进即静默勾（无确认门）——跳读/略读被算完成，用户失去否决权
- 显式申报式（阅读器里「读完本章」动作）——精确但打断阅读流，fork UI 改动最大

## 关键约定

- **桥面**（fork 侧，public 成员 `planflowBridgeApi` 挂插件实例，Dataview/Templater 惯例）：`getBookshelf()`（书目 + 阅读状态 + 位置章序）、`getToc(sid)`（目录树 + 叶 → spine 锚点）、`openChapter(sid, 锚点)`、位置推进事件（window CustomEvent，detail = sid + 推进区间 `[fromChapter, toChapter)`；越过叶子由 planflow 依目录对齐推导——目标结构与目录**逐叶名字比对**一致才联动，手动改过结构 → 联动停用并提示一次，绝不静默错勾）
- **降级**：全局设置开关默认开；fork 缺席 / 书不在架 → 静默回退粘贴导入，绝不因桥缺席弹错；单书目录读取失败 → 引导性提示（非错误弹窗），粘贴入口就在旁边（ADR-0007 降级纪律）
- **建目标流程**（阅读书籍模式专用步骤序，其他模式不动）：模式选择 → 选书（书架列表全架列出：标题+作者+状态徽章+进度，fuzzy 搜索不必需——个人书架量级小；书名即目标名）→ 选中自动拉目录 → 目录确认（节数统计 + 首末叶预览 + 接续阅读行，可回层级页微调）→ 日期步 → 自动分配；粘贴入口保留并存；同书同时仅一个**未完成**目标（全勾完 = 可建重读目标）
- **单位词**：从目录标签猜（「第3章」→ 章，复用 toc.ts 词表），猜不到落默认链
- **真实标题进任务名**：目录标签随结构落盘（`GoalLevel.labels`，DFS 序），叶任务名用真实标题（重排型叶带「{汇总组路径}·{标题}」前缀保唯一，如「第1章 初见·第一节 相遇」）；自动任务识别正则同步扩展到纯数字/中文数字编号后缀；标签与结构在结构确认步可改名/调整，确认后才落盘分配
- **接续阅读**：建目标时已越过部分预勾，每日分配只覆盖未读叶；进度口径不变（已勾 ÷ 总节，预勾计入分子）
- **推进事实 + 确认门**：实时推进 → Notice 逐条确认（✓勾选 / 忽略）；忽略 = 一次手动决策，落 `✋`，此后自动不问不勾；点空白处关掉 = 本次不处理（推进/对账再问）；对账兜底——打开今日面板按书架当前章序批量确认补勾（重启 / 跨设备最终一致，只重放同一条推进事实，不引入第二口径；1 分钟节流——兜底不是追问）
- **单向只勾不退**：回读不退勾；退勾只能手动（落 `✋`）
- **跳转**：叶子行尾 🔗 → `openChapter` 活解析叶子 → 锚点；书行 🔗 → `openBook`（恢复上次阅读位置；旧版 fork 无此方法时按钮不显示）；目标只存 sid 不落锚点，书文件指纹可校验一致性；叶行锚点异步补齐（首帧缓存未就绪时解析完自动刷一次）
- **手动优先**：沿用 ADR-0006 MANUAL_MARK，`✋` 行自动逻辑一律跳过
- **单书书组**：今日待办单书也折叠书行（修订 ADR-0008 的 ≥2 呈现阈值，用户偏好 2026-11-09）；书组归属在编号后缀正则外增加已知目标名前缀匹配——真实标题无编号（如「（序）」）的叶不游离书组外

## 补遗（2026-11-11，ADR-0013）

本 ADR 初版规范只写了叶子勾选，漏了父行级联——推进/对账经 `applyWeaveCheck` 勾叶后不回写计划父行，曾导致「3/3 本、书行全勾、父行永不勾」。父行回填不补在本路径：一切勾选来源统一由刷新期父行对账收敛（ADR-0013），本路径只负责把叶子事实落对。
