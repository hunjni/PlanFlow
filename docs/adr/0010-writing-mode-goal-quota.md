# 写作模式（writing）：目标级字数配额 + 章节平铺复用结构引擎

用户要「写小说」类项目：按字数或按章节量化，两种方式由下拉按需选择。ADR-0001 的 quota 引擎正是为「写 10 万字小说」设计，但它挂在**计划级**（`PlanDef.quota`，一计划一定义），且创建无 UI（frontmatter 手写）；ADR-0006 已确立目标模式预设层（reading/review/diary/exercise）。写作作为第五个目标模式进入预设层；按字数需要 quota 语义随**目标**走而非随计划走。

## Considered Options

- 按字数复用计划级 quota（向导代写 frontmatter）—— 一个计划只能挂一本按字数的书，多书并行 / 字数与章节目标混挂时口径分裂；计划级 quota 保持原样不动（本 ADR 不改它）
- 目标级 quota（`PlanGoal.quota`），每日配额沿用 ADR-0001 口径、冻结进 `floor` 字段（**采纳**）
- 按章节自建写作引擎 —— 现有结构引擎（1 级「章」结构）+ 分解 / 编辑重排 / 接续预勾全套免费，自建是重复造轮子

## 关键约定

- 写作模式 = 模式卡「✍️ 写小说」；表单顶部下拉选**量化方式**（按字数 / 按章节）。编辑禁止跨口径切换（字数账 = 每日行累计、章节账 = 任务池勾选，两套账互不相通；换口径 = 删除重建）
- **按字数**：`goal.quota = { total, unit: "字", start, end, initial }`；`goal.floor = (total − initial) ÷ 天数`——创建时一次算死、落后不自动追赶、勾选 = 记满当日配额、`（实 N字）` 可选、✋ 手动优先，全部沿 ADR-0001/0007，不造第二套字数口径。进度 = (initial + Σ行事实) ÷ total；行事实 = `（实 N）`，无实际量勾选日按**行内**配额数记（历史行配额不随编辑漂移，文件事实为准）
- 每日行 = 模式行机制（惰性补写、挂计划父行下、「实」按钮；实 ≥ 当日配额自动勾）——与复习/运动同构，`floor` 冻结的配额数恰好充当模式行识别记号
- **按章节**：`structure = [{ unit: "章", counts: [N] }]` 平铺，任务「{书名}（第 X 章）」进任务池均匀分日（与通用数量目标同构：今日到期、周/月/看板/甘特全部免费）；接续 = 前 M 章预勾（与接续阅读同一实现：锚点日 = 窗口前一日，剩余章重摊）；进度 = 已勾章 ÷ 总章
- 无外部事实源（字数在稿件里、不在 Obsidian 里）：纯手动记录，无 BZG 式自动逻辑
- 统计路由：writing + quota → 写作专属统计（累计字数 / 落后判定 / 动笔天数）；writing 无 quota → 任务池口径（同阅读 / 通用）。写作字数目标计入「计划仅有模式目标时进度 = 模式目标均值」的口径
- 接续写作：建目标时可声明已完成章数 / 已累计字数（`initial`）——章节预勾前 M 章、字数记初始累计量，进度口径不变（初始量计入分子）
- 成就系统本期不接（先跑通核心闭环）
