# 今日打卡大项口径：顶层行计数，模式子行折叠进父行

进度与连续打卡若按「行数」计数，模式目标（复习/日记/运动，ADR-0006）会让一个计划占多行——用户在界面上说的是「大项完成没」，不是「每行完成没」。本决策规定今日打卡的计数单位是**大项**：顶层行 = 非模式行；同计划第一个非模式行是该计划的父行，模式行嵌套其下（与 updateChecklist 的渲染嵌套同一规则）；父行聚合完成态 = 自身已勾**或**全部模式子行已勾（「勾满子 → 父自动勾」级联的回填间隙不吞完成度）。任务池子任务（阅读书叶等）不进此口径——它们有自己的今日书进度（ADR-0008）。无父行的模式行保持顶层（渲染同款兜底）。

## 消费方（同一把尺）

今日打卡进度（打卡卡）、连续打卡（每天全部大项完成才计一天）、成就系统的完成判定（achievements.ts）。

## 取舍

- 大项数 = 大项完成数与行级计数并存（顶层行计数徽章沿用 ADR-0003 双计取舍），界面上进度卡按大项、徽章按行——两处口径各自成立，均以本决策的嵌套规则为尺。
- 父行勾选优先于子行聚合：父行已勾即完成，即使个别模式子行被手动退钩（父勾是更早的用户决策，不因子行波动回退）。
