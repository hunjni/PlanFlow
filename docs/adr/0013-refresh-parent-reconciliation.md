# 刷新期父行对账：待办清空 → 勾父，一切勾选来源统一收敛

ADR-0003/0008 的父行规则（「该计划全部待办清空 → 父行自动勾」）原本只挂在今日打卡的两条**交互**路径上（勾叶、勾书行）。自阅读联动静默自动勾成为默认（6482e1c），叶子常由非交互来源勾掉：weave 推进/对账（ADR-0009 的规范只写了叶子勾选，漏了父行级联）、年/月/周卡勾任务、外部编辑——父行从此落后于事实，且唯一会在刷新期回填父行的 `ensureModeGoalTracking` 因其模式口径明确排除阅读目标，用户遇到「3/3 本、书行全勾、父行永远不勾」，连续打卡与今日打卡进度（ADR-0012）同步把阅读算未完成。本决策把父行规则**对账化**：挂在今日刷新链（所有勾选来源都经 `refreshToday` 收敛，与份额清空提醒同一收敛点），每次刷新统一检查——父行未勾 && 无 ✋ && 计划今日在任一目标窗口内 && 全部模式子行已勾（依文件事实）&& 任务池待办清空 → 勾父行。全计划同一把尺（阅读、写作按章节、普通数量型），不只修阅读。

## Considered Options

- 每个非交互勾选入口各自补级联（`applyWeaveCheck`、`togglePoolTask`…）—— 每处新增「定位当日笔记父行」的管道，外部编辑依然漏，碎片化正是旧两条路径的老路
- 只修 reading —— 对账条件本就计划无关，写作按章节勾满周卡任务时同样的坑再踩一遍
- 刷新期集中对账（**采纳**）—— 单点覆盖一切来源与历史遗留状态（自愈），与 ADR-0011 事实镜像哲学同向

## 关键决策

- **活窗口守卫**：计划任一目标今日在窗口内（`start||period.start ≤ 今天 ≤ end||period.end`，与模式回填同口径）才参与对账。纯打卡行/定额行无目标 → 恒不自动勾（没有完成事实可言）；窗口已过的计划不再日日白勾。
- **父行判定与渲染嵌套同一把尺**（ADR-0006/0012）：同计划第一个非模式行；同计划不重复定位。
- **模式子行完成态依文件事实**：对账跑在模式回填（`ensureModeGoalTracking`）之后，文件里模式行已是事实态，无需跨函数传递内存态（原函数内的父行级联块与 finalChecked 管道已上移收编，防两把尺漂移）。
- **单向镜像（ADR-0011 推广到计划父行）**：手动取消父行不落豁免，事实未变时刷新即重勾。叶子全勾时取消父行，除误触外无合理动机；真要长期免勾，父行手加 ✋（本对账沿用的豁免记号——与模式行不同，父行 ✋ 被尊重而非清除）。
- **✋ 豁免叶天然阻塞**：待办口径（未勾且已开始）不区分 ✋，用户忽略的叶保持未勾即留在待办里，对账不会在用户明确拒绝的单位上勾父行——无需新机制。
- **幂等自愈**：已勾跳过；面板没开就不跑，下次打开自愈（与 chime/模式回填同一模式）。

## 取舍

- 刷新期对账非即时：weave 勾完最后一叶到 `refreshView` 重渲染之间父行短暂未勾——所有勾选来源本就经刷新收敛，实际间隙为一次重渲染；交互路径的即时级联保持不变。
- 窗口内且叶子全部完成（含提前读完）的计划，其父行在窗口内每天被对账勾上——与今日书进度徽标「份额清空即完成」的既有语义一致（ADR-0008），且比「已完成计划天天拖累进度与连续打卡」更符合直觉；窗口结束即止。
- 连续打卡/进度在本轮刷新先算、对账后写——首刷延迟一轮收敛，与既有回填位次一致。
