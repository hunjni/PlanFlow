# 模式行取消手动豁免（✋ 仅存于阅读联动）

2026-11-10 事故驱动：用户完成 17 篇复习后复习行毫无反应。复盘发现 ADR-0006 的「手动优先」是根因——当天早些时候手动点过一次复习行的勾选框，行上落下 `✋`，此后整天的自动逻辑（实数回填 + 自动勾选）一律静默跳过该行。触发源（BZG review.json）、监听器、刷新链路全部正常，败在一个用户不可见、不可恢复的标记上。用户裁决：取消这套豁免——勾被取消了，再次触发就再次按事实自动勾上。

## Considered Options

- 保持手动优先，补文档 + 排障日志 —— 静默失效的坑还在，下次照旧排查半天
- 收窄豁免（退勾才落 ✋；✋ 只拦勾选不拦实数）—— 保留「别勾我」语义，但 ✋ 概念分叉成两种行为，且用户明确表示不需要
- 彻底取消模式行豁免：勾选/实数是完成事实的镜像，自动回填不跳过任何行（**采纳**）；`✋` 仅保留给阅读联动的推进事实（ADR-0009 点忽略/联动叶退勾——那是用户对**预测**的否决，语义本就不同）

## 关键约定

- 模式行（复习/日记/运动）任何写回路径不再落 `✋`：手动勾/退勾走普通 toggle，「实」按钮写回不带标记
- 自动回填不再跳过 `✋` 行：复习按 BZG 当日去重文档数回填实数与勾选，日记按日文件写作内容勾选，运动无自动
- 存量残留 `✋` 由回填顺带清除（`clearManualMark`；`setQuotaActual` 重建行时同样剥除）——阅读联动的 `✋` 不走模式行回填，不受影响
- 每行至多一个写回操作（防 `expectedRaw` 定位互踩）：回填循环里各分支互斥，残留清理仅在无其他写回时落 `clearManualMark`
- 手动勾/退勾仍然即时生效，只是不再持久豁免：下次事实刷新即按事实回填（事实未变 → 勾被重新落上）
- 「手动优先」概念自本 ADR 起仅存于阅读域；CONTEXT.md「完成事实镜像」词条为语义出处
