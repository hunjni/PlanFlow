# 今日级联按书分组：书组是派生视图，进度按书计数

多本书并行阅读时（同一计划下多个结构目标），今日打卡的子任务按 ADR-0003 级联全部混排在一个扁平列表里，无法回答「这本书今天读完了没」。本决策在**视图层**把级联子列表按目标（书）分组，新增书行（可勾）与今日书进度分数（如 1/3 本）：**不改文件格式、不改统计口径、不改父行规则**——书组是运行时从任务池事实推导的派生展示，不是新的存储事实。

## Considered Options

- 书行写入每日笔记（两级嵌套任务行）—— 任务池与每日笔记出现重复状态，需要新的写入/同步逻辑，统计与日记投影口径全要跟着改，违背「统计一律以文件事实为准」（ADR-0001 原则）
- 全书口径（读完整本书才计 1/3）—— 与「完成今日份额即打勾」的日常节奏脱节，且若父行自动勾也按此口径，要全部书 100% 读完才勾今天的阅读行（通常隔多日）；用户明确排除：今日打钩界面只回答「今日份额完成没」
- 视图层分组 + 派生书行（**采纳**）—— 复用 ADR-0003 级联与 ADR-0005 命名前缀，文件、统计、日记投影零改动

## 关键决策

- **分组触发 = 「今日有安排的书」≥ 2**，不是「有待办的书 ≥ 2」——否则某本书勾完后整组消失，与「保留已勾书行」矛盾；单书/单目标计划保持扁平列表不加冗余层；手动临时任务与识别不到目标名的任务（遗留 plan 级分解）不分组，平铺在子列表顶部。
- **今日有安排的书 = 阅读窗口覆盖今天（🛫 ≤ 今天 ≤ 📅，跨日窗口起读当天即计入）或有逾期欠账**；窗口未开始、已读完的书不进分母。顺延分摊保证窗口内每一天至少一叶的窗口覆盖当天；只看 📅 = 今天会漏掉跨日窗口的叶（🛫 = 今天、📅 = 明天的叶起读当天勾了也必须计今日完成）。
- **书名归属 = 任务名前缀**：ADR-0005 命名 `{goal.name}（叶路径）`，剥掉尾部 `（第…）` 后缀即组名，无需查目标清单。
- **书行语义镜像父行**（ADR-0003 下沉一层）：勾书行 → 连带勾该书全部待办叶（写任务池 + 日记投影，与逐叶勾同路径）；该书最后一叶勾完 → 书行自动勾；取消书行不回退叶子。
- **书行勾选是派生态，不落任何文件**：状态从「该书待办是否清空」推导，因此已勾书行的 checkbox 不可直接取消（派生态无法单独置否）。反悔路径 = 点已勾书行展开今日已勾叶、逐叶退钩；退到非全勾，书行自动回未勾。
- **逾期欠账阻塞完成**：该书今日份额含逾期叶，欠账清完才算今日完成（诚实呈现欠账，ADR-0001 哲学）。
- **今日书进度 = 份额清空的书数 ÷ 今日有安排的书数**，父行右侧小字「1/3 本」，仅多书计划显示，每天重算、不跨日累计；「今日进度」徽章保持顶层行计数不变（ADR-0003 双计取舍沿用）。
- **父行规则一字不动**：该计划全部待办清空 → 自动勾；勾父行 → 连带勾所有书全部待办；取消父行不回退。
- **完成组保留显示**：已勾书行打勾、其叶子隐藏（沿用「子列表只显示待办」）。
- **机制计划无关**：任何数量型计划的多目标（如写作多篇）同样适用，非阅读专属。

## 取舍

- 文案极简：组头只有书名，不显示余量/进度数字——组内待办叶本身就是余量清单。
- 组顺序 = 任务池文件顺序（= 建书顺序），稳定不重排。
- 分数每日重置是特性不是缺陷：今天 1/3，明天书 A 又有新份额则回到 0/3；「整本书读完」口径不进任何界面。
- 预读（提前勾明天的叶）→ 明天该书自然显示已完成，视为超前完成的诚实呈现，不做特殊处理。
- 全部派生、无缓存无持久化：分组键、分母、分子每次渲染从任务池事实现算，视图关闭即消失。
