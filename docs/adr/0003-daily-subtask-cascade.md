# 今日打卡父子级联：任务池任务嵌套为计划行的下一级子任务

用户需求：量化计划（如「阅读」）在今日打卡区的行下面，直接列出当天需要完成的任务（任务池中该计划已分解的任务），逐个打勾；全部完成自动勾掉上一级计划行；当天没完成则打卡记录保持未完成，且未完成任务顺延到第二天继续出现。

## 关键决策

- **子任务来源 = 任务池，不新生成**。数量型计划已有 ensureAutoTasks 按目标窗口分解任务到任务池（`任务.md`），今日打卡的子列表直接复用：`plan 匹配 && 未勾选 && 已开始（🛫 ≤ 今天，无 🛫 用 📅 兜底）`。无日期任务不进子列表（与 `filterTasksInRange` 口径一致）。
- **「顺延」= 自然顺延，不改日期**。未完成任务 🛫 早已 ≤ 明天，第二天打开今日视图仍出现在子列表里；不做任何日期改写，统计继续以文件事实为准（沿用 ADR-0001 原则）。
- **级联方向**：子任务全勾完 → 父行（每日笔记行）自动打钩；勾父行 → 连带勾掉该计划全部待办子任务（一次全做的场景）；**取消父行不回退子任务**——防误触把任务池里的进度记录批量清掉。
- **quota 型计划不在本次范围**：配额行继续用「实际量（实 N）」按钮记量（ADR-0001），不拆子任务。若未来需要按量拆分（勾一个子项累加实量），另开 ADR。
- **写入路径**：子任务勾选写任务池（复用 `toggleTask`），父行写每日笔记（复用 `toggleTaskLine`）；子任务勾完后调用 `refresh()` 统一重算 planProgress/周卡/打卡区。

## 取舍

- 今日进度（0/6 徽章）只数顶层计划行，不数子任务——子任务是父行的分解，双计会虚高。
- 子列表只显示待办（已勾的消失），父行自动打钩即「全部完成」的视觉信号。
- 过期任务会随拖欠累积在子列表里（诚实呈现欠账），不设上限——这是「顺延」的直接后果，用户可删任务池任务来减负。
