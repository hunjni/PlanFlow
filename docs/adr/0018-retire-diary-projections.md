# ADR-0018 · 日记三节投影退役：写入权归 BZG 单点

日期：2026-11-13 · 状态：已采纳 · 关联：ADR-0004（本条废止其「代办事项/完成情况跟踪」两处投影）、ADR-0017（次行不投影日记随本条失效）、BZG ADR-0301（三节最终模型）

## 背景

ADR-0004 让 planflow 在勾选时向当天日记写「## 代办事项」「## 完成情况跟踪」。BZG 侧后来又实现了 diary/plan-mirror，也写同样两节（ADR-0296/0297）。结果是**双写**：

- planflow 按「标题匹配 + 追加」写，`文献复习 5篇（实 N篇）` 每变一次就多一行；
- BZG 整节重绘，两边互相覆盖；
- BZG 旧版的「抢救 / 清重」启发式又把计划行搬进 `# 日常行为记录`，三节全部污染。

用户最终口径（见 BZG ADR-0301）：三节各归其位、内容与勾选一一对应。

## 决策

1. **删除两处日记投影**：`syncPoolTaskToDiary`、`projectTransform`、`syncPlanTrackingToDiary`、`trackingTransform` 及全部调用点（今日打卡勾选、书行级联、父行级联、任务池勾选、阅读联动 `weave-runtime`）。planflow 不再写「## 代办事项」「## 完成情况跟踪」一个字节。
2. **保留用户主动触发的日记写入**：「## 备注」今日总结、「# 当日复盘」、「# 次日计划」——它们与计划镜像无关，仍由 planflow 写。
3. **保留 `diaryDir` 设置**，文案改为「日记目录（复盘/次日计划）」。
4. **三节由 BZG 依据计划事实重建**：BZG 监听每日笔记 / 任务池 / review.json 的变化，整节重绘并做勾选双向回写。planflow 侧无需感知。

## 后果

- 日记三节单写者，重复行与勾选错位消失；BZG 的镜像成为唯一事实投影。
- planflow 的「勾选 → 日记」路径不再存在；日记由 BZG 监听计划文件变化自动跟上，用户观感不变。
- 若用户禁用 BZG 或关闭其镜像，日记三节将不再更新——这是「单写者」的明确代价，优于双写互抢。
- ADR-0017 中「次行不投影日记」的前提消失（planflow 不再投影）；BZG 按「最末可勾叶」自行决定次行进代办事项。
