# 新增第三种计划类型「日定额型（quota）」

PRD v1.1 规定「计划分解到任务为最低粒度，不分解到日」，但连续量目标（写 10 万字小说、读 300 页书）既无法表达为打卡型（无总量概念），也不适合数量型的离散任务分解（无法均分到天）。故新增 `quota` 类型：定义 `总量 + 单位 + 截止日`，每日配额 = 总量 ÷ 计划天数，**创建时一次算死、落后不自动追赶**（避免「越落后越吓人」的心理压力，进度偏差仅在视图提示）。

## Considered Options

- 扩展数量型按日期排任务 —— 改动大，且「每天 1170 字」不是离散任务
- 只加「节奏线」不改模型 —— 无法满足每日打卡与实际量记录

## 关键约定

- 实际量为可选项：勾选 = 记满当日配额；填实际量则按实际量累计进度。markdown 记法用括号后缀：`- [x] ✍️ 写小说 1170字（实 800字） #计划/小说 🛫 … 📅 …`
- 每日配额行写入每日笔记「今日打卡」区，**惰性生成**（打开今日视图时幂等补写当天行，不打开不写文件），绝不改历史行
- 单位自由填写，插件只认数字；文档建议用可分割单位（页/章/字/分钟）
- 不做补卡 UI：漏卡直接手改过去日期的文件，统计以文件事实为准（见 CONTEXT.md「补卡」）
- quota 行计入今日视图「今日进度」口径
- 周/月/年度视图显示：进度条 = 累计实际量 ÷ 总量 + 「今日配额 N」角标 + 落后暖红提示；燃尽图/节奏曲线留二期
- 定义方式：沿用 `年度计划.md` frontmatter，计划对象加 `type: quota` + `quota: {total, unit, end}`；UI 弹窗建目标留二期
