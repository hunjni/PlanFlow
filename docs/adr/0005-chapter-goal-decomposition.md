# 数量型目标新增「章节型 → 分级型」形态：多级单位树分解

用户需求：设置阅读计划时输入书名，然后**逐级**定义单位树（篇 → 章 → 节…，1~3 级）：每一级选单位词（篇/卷/部/章/回/课/讲/节 + 自定义）、输入上级各节点的子数目，且**每一级都可以选「完成」停在那里**（只排到篇 / 排到章 / 排到节）——叶子即逐日可勾选单位，按既有目标时间窗自动分摊到每天，读完后能逐节辨识勾选。同一时期可并行多本书。

## Considered Options

- 扩展扁平分解加二级命名 —— 与本方案同形，但扁平「（第 N 篇）」的连续编号无法表达章边界，章级进度无从算起
- 新独立计划类型「阅读型」 —— 复制一套任务池/级联/进度/墓碑逻辑，维护成本翻倍
- quota 型按「节/天」记量 —— 勾选粒度是天不是节，无法满足「逐节辨识勾选」
- 固定两级「章→节」 —— 无法表达篇/卷/回/课等真实书籍与课程的层级（v2 升级动因）

→ 选定：**数量型目标的可选多级结构形态**（goal 加 `structure` 字段，兼容旧 `chapters`），复用任务池、今日级联（ADR-0003）、前缀进度、墓碑全套机制。

## 关键决策

- **章节序列是扁平的**。分解时把单位树展开为线性叶子序列（书序 = DFS 序），再走与扁平分解完全相同的均匀分布公式（叶 k：🛫 = 窗口起 + ⌊(k-1)×天数÷总叶数⌋，📅 = 下一叶起读日前一天；除不尽时前面几天多一节）。不为「章」单独对齐日期——章边界落在哪天就是哪天。
- **子数目允许填 0（变深树）**：某节点没有下级内容（如第 5 章无节）时填 0，该节点本身升格为叶子——任务即「第 5 章」，读完整章勾一下。叶出现在不同层级，勾选粒度逐节点自适应；升格节点的进度组标签用自身名（如「第 2 卷 1/1」）。全 0 的级 = 该级整体跳过、上一级全部升格。第 1 级总数仍须 ≥ 1，整级至少一项 ≥ 1（全 0 应改为在上一级点「完成」）。
- **编号按真书惯例**：重排型单位（场/节/小节/目/条）**每上级从 1 重新编号**；其余单位（部/编/卷/辑/篇/单元/模块/章/回/课/讲/集/幕）**全书连续编号**——第 2 篇的章是第 3、4、5 章。节编号重排是它作为「上级内小节」的语义，章连续编号让叶名在全书中唯一。词表与接续推荐（篇→章→节、单元→课、幕→场）见 `STRUCT_UNITS`/`UNIT_SUCCESSORS`。
- **命名 `{书名}（叶路径）`**：全局型叶 = 自身全局标签（排到篇=「第 2 篇」、排到章=「第 5 章」）；重排型叶 = 沿上级链收集**连续重排段**，锚定最近的全书连续级（章→节=「第 5 章第 2 节」；章→节→小节=「第 5 章第 2 节第 1 小节」，与书内 1.2.1 式目录编号一致；幕→场=「第 2 幕第 1 场」）。重排型叶必须带路径——裸「第 1 节」会跨章撞名（第 1 章和第 2 章都有第 1 节），进度组标签同理用路径式。括号惯例与「（第 N 篇）」一致，`${goal.name}（` 前缀匹配（进度统计、删除联动、改名联动）不用改。不用简写 `1/1`——多本书的子任务在级联列表混排时简写不可辨识。
- **逐级数目存结构** `structure: [{unit: 章, counts: [3]}, {unit: 节, counts: [2, 3, 4]}]`（frontmatter 块序列，level 0 counts=[总数]，level n counts=按上级书序逐项）；`count` 恒等于叶总数，`unit` 恒为叶单位。旧 `chapters: [2,3,4]` 仍解析并等价转换为 章→节 两级结构（命名逐字兼容）。
- **`isAutoTask` 通用化**：任务名以「（第<数字>…）」后缀结尾即视为分解任务（覆盖任意单位词与多级路径、含自定义单位）。误判手动任务只会让删除多打一条墓碑，无副作用。
- **编辑结构目标 = 按名对账 + 剩余重排**，不是删光重建（对扁平目标保持原行为）：新序列里仍存在的任务**保留勾选状态**——读书中途调节奏是常态，丢勾选等于丢进度；其中**未勾的叶子作为「剩余序列」从新窗口第一天起重新均匀摊开**（重排时点已勾的叶不占新窗口位置，其原日期保留作进度记录；全未读时剩余序列 = 全序列，与初次分解一致；窗口未变则零写入）；已不存在的叶子任务删除（防虚增进度）；缺的任务补生成。墓碑相应只清理「新序列里已不存在」的名字，用户手动删过的叶编辑后不复活。
- **欠账不自动追赶**（沿用 ADR-0001 哲学）：某几天没读，未读的叶子靠今日级联自然顺延累积（诚实呈现），插件不改写日期；「重排」只发生在用户主动编辑目标时——长时间搁置后重启阅读 = 把开始日期改为今天 + 给新的天数。
- **章级（组级）进度**：年度卡目标行下按**倒数第二级**汇总展示（排到节→每章一行 x/y；排到章→每篇一行；排到篇→只看总进度），当前组（第一个未读完的）高亮；组数 > 12 折叠为紧凑单行文本。

## 取舍

- 各级数目允许不同（逐项输入），不接受「每章统一 n 节」的快捷输入——真实书籍章节普遍不均匀，统一假设会逼用户拆目标。
- 结构级数上限 8（防御性；真实书籍/课程 1~4 级足够， deeper 层级命名消歧规则仍成立——全局级唯一、重排叶退化用全局号保唯一）。
- 弹窗「天数」快捷输入只改 UI（开始 + 天数 → 算出结束日期存盘），数据模型仍是 start/end，不改 frontmatter 格式。
- 结构型目标不新增计划类型/视图：今日该读哪些叶子由 ADR-0003 级联自然呈现（🛫 ≤ 今天且未勾），逾期顺延，不设「今日安排」独立区块。
- 转换形态（结构 ↔ 扁平）走编辑流程：按对账规则清理不存在的名字后重建——不做自动迁移。
- 进度组标签带空格（「第 1 章」）与任务名风格一致；旧版无空格的进度文案不再出现。
