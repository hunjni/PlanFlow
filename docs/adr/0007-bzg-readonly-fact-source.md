# BZG 只读文件联动：复习/日记模式的完成事实源

复习模式要"自动知道今天实际复习了几篇"、日记模式要"写了日记就自动打钩"，前提是 vault 里有可检测的事实。用户同时使用 BZG 插件（复习 SRS + 日记系统），其 review/diary 域已冻结（行为/UI/数据一律不动），因此联动**只能是 planflow 单向只读文件**。这突破了 ADR-0004"统计从不读日记"的边界——补一条例外而非推翻：planflow 读的只是日记日文件中**本人亲手写下的内容**（`# 随笔`/`# 当日触动点` 小节的正文行），不碰投影区（`## 代办事项`/`## 完成情况跟踪` 是 planflow 自己写的，读它们会循环自证）。

## Considered Options

- 让 BZG 暴露 API/事件配合 —— BZG 侧冻结域，一行不改，不可行
- 读文件（review.json + 日记日文件）（**采纳**）—— BZG 无任何对外接口，纯文件落盘是唯一数据面
- 监控文件浏览行为推断复习 —— "打开 ≠ 复习"，且漏计 Obsidian 未开启的时段，最不准

## 关键约定

- **数据面**（以 BZG 自身 `data.json` 的真实配置为准，读不到按约定路径兜底）：
  - `CONFIG/STORAGE/review.json`：每次评级整写；`reviewHistory[].timestamp` 为 UTC ISO，**按本地日聚合、按文档去重**（同篇一天多次评级算 1 篇）
  - `我的/日记/{YYYY-MM-DD}.md`：日文件打开即预铺骨架，**文件存在 ≠ 写了**；完成事实 = `# 随笔` 或 `# 当日触动点` 小节存在非空正文行
- **监听**：vault modify/create 事件命中上述路径（review.json 整写 / 日记日文件）→ 防抖刷新；planflow 自写期间（selfWrite）不响应
- **降级**：设置页"BZG 联动"开关（默认开）；BZG 缺席 / review.json 不可读 → 快照为 null，静默降级为手动（复习用行内「实」按钮，日记手动勾选），绝不弹错
- **手动优先**：用户手动勾/退勾、手动填实际量的行打 `✋` 标记，自动逻辑永不再碰（含"日记明明写了但用户退勾"的场景——规则一致性优先于直觉）
- **只读边界**：planflow 从不写 BZG 的任何文件；日记里的 bz 时期遗留跟踪区（`## 完成情况跟踪` 勾选清单）非 BZG 现行契约，planflow 不读不写
- 文献池 = BZG `reviewCountFolder`（用户实际配置 `卡片盒/文献`）下的 md 文档数，动态计数不复制清单；用户在 BZG 换文件夹后 planflow 跟随
