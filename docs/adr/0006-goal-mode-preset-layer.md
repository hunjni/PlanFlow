# 目标模式（goal mode）：预设层而非新统计类型

年度计划里"不同类型的目标需要不同量化方式"（阅读/复习/日记/运动……），但计划量化类型（数量/打卡/日定额）是引擎口径，不是语义分类——"阅读"之所以好用，只是「数量型 + 多级结构」恰好覆盖了它。ADR-0005 曾否决"新增独立阅读型计划"，理由是结构是形状不是类型。本决策在**量化目标**层引入语义模式，但坚持它只是**预设层**：模式决定向导流程与进度呈现语境，统计一律落在既有引擎（或其最小扩展）上。

## Considered Options

- 模式 = 新的一层独立统计类型 —— 改动大、与 ADR-0005 的裁决冲突，且用户要的统计原语（打卡率、每日配额+实际量、结构分解）几乎都已存在
- 模式 = 向导预设 + 既有引擎映射（**采纳**）—— 统计引擎只加一个最小变体：复习模式的「无总量、纯每日下限」

## 关键约定

- 模式挂在**量化目标**上（`goals[].mode: reading|review|diary|exercise`），计划仍是自由分类，一个计划下可混模式；frontmatter 键用英文 `mode`（计划级 `模式:` 键已被计划量化类型占用，勿混用）
- **undefined = 通用模式**：既有目标零迁移，行为完全不变；阅读书籍模式 = 现有结构向导 + 目录粘贴导入（`src/toc.ts`：单位词编号 / 1.2 数字编号 / 缩进三线索混合解析，结果进确认页可微调）
- 复习模式 = 纯每日下限（`goals[].floor`）：无年度总量、无截止日——BZG 的 SRS 复习队列是开放流，人为总量是假口径；进度 = 达标天数/应达标天数 + 连续达标 + 覆盖率（年内不同文献 ÷ 文献池），**累计复习次数不作任何口径**（同篇重复复习使它与文档数永远对不上）
- 日记模式 = 打卡行 + 自动勾选；运动模式 = 打卡 + 可选每日量（`floor`），手动记录
- 模式目标（review/diary/exercise）**不进任务池分解引擎**（ensureAutoTasks 过滤）；复习/日记/运动的每日行 = 打卡区惰性补写（与 ADR-0001 quota 行同构：已存在的行一律不重建）
- 无任务池事实的模式目标计划：年度进度 = 各模式目标达标率均值；年度目标行显示模式徽章（📖/🔁/📝/🏃）+ 专属口径文本
- 手动优先：模式行被用户手动勾/退勾或手填实际量后打 `✋` 标记（`MANUAL_MARK`），此后自动逻辑一律跳过该行；未达下限的实际量也照实记录（不勾选）（**2026-11-10 起取消**——ADR-0011：模式行事实优先、无 ✋ 豁免，一次手动触碰即整天静默的事故见该 ADR）
