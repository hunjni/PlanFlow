# planflow 打卡联动日记「## 代办事项」（与 bz 待办投影同格式）

用户需求：在 planflow 里勾选计划的子任务（如「阅读 第一节」）时，向当天日记（`我的/日记/YYYY-MM-DD.md`）的 `## 代办事项` 小节**添加并勾选**该内容——格式与机制完全沿用 bz 待办（ADR-0122/0123）对 TODO 的处理方式。

## 关键决策

- **投影格式与 bz 逐字同源**：`- [x] <序号>. <标题>-<HH:mm>`；序号接当天小节既有最大号续号（含手打编号行 `- [ ] N.` 占号，与 bz diary-projection 同口径），时间 = 勾选时刻。
- **匹配键 = 标题**（planflow 侧不需要 id）：勾选 → 已有同标题行则勾上（幂等），没有则新增勾选行；退钩 → 已有行退回 `[ ]`（同 bz「面板恢复 ↔ 日记退钩」），没有则不动；重勾复用同一行不产生重复。
- **单向投影，不做反向**：日记行改动不回写任务池（bz 有双向 + 回声抑制快照，planflow 子任务真源在任务池，反向收益低、复杂度高；如日后需要再开 ADR）。
- **不为日记建结构**：日记文件或「## 代办事项」小节不存在 → 静默跳过。日记骨架由 QuickAdd/bz 负责（bz ADR-0123 的建档职责不搬到 planflow）。
- **投影范围**：任务池任务的任意勾选入口都投影——今日打卡子任务（togglePoolChild）、勾父行级联勾掉的子任务（toggleCheckItem）、周/月卡等通用路径（togglePoolTask）。顶层计划行（每日打卡行）不投影——它是每日循环模板，不是 TODO。
- **配置**：新增设置「日记目录（打卡联动）」，默认 `我的/日记`，留空禁用。
- **失败不阻断打卡**：日记写失败只记 console.error，主流程（任务池勾选）已完成。

## 取舍

- 退钩选「退回 [ ]」而非删行：与 bz 行为一致，日记里保留「做过又取消」的痕迹，重勾不换号。
- 无反向同步的代价：在日记里手动改行不影响任务池——日记行是投影不是真源（TodoItem 们在 memo.json 有真源，planflow 子任务真源在 任务.md，同理）。
- projectTransform 为纯函数并配了 8 项单测（新增/幂等/退钩/重勾/手打占号/无命中/无小节/节边界），测试方式：esbuild 转译 + stub obsidian 后 node 直跑。

## 扩展（2026-09-24 下午）：今日打卡计划项 → 「## 完成情况跟踪」

用户补充需求：既然退钩保留行，就把**今日打卡的全部计划项**（顶层 plan 行，不含临时任务）也写进当天日记，但**不进「## 代办事项」**——落在模板既有但闲置的 `## 完成情况跟踪` 小节。

- **格式**：复选框行 `- [x] <计划项文本>`（无序号无时间戳），放在小节标题下、表格上方——与表格互不干扰，表若哪天手动填复盘内容也不冲突（Q1a，否掉了「填表格行」方案：表格行匹配脆弱、列语义拧巴）。
- **时机**：确保存在 + 实时镜像（Q2a）——今日面板每次刷新（视图打开/vault 变更防抖）把缺失的计划行补齐（含未勾选的），勾选态每次同步；顶层行勾/退钩（toggleCheckItem）立即镜像。这样「没完成的也有记录」成立。
- **语义对齐**：勾/退钩与 TODO 投影同规则（退钩保留行、幂等、匹配键=标题）。
- **边界**：小节或日记文件不存在 → 静默跳过（不建结构，同上）；计划项中途改名/删除 → 旧行保留不自动清理（防误删手动内容），新名字下次刷新补新行。
- **实现**：`trackingTransform` 纯函数 + `syncPlanTrackingToDiary`，复用同一 `diaryDir` 设置；触发点两处（今日面板数据装载后、toggleCheckItem 顶层行变更后）。配 12 项单测（首镜像/幂等/勾态镜像/新计划追加/计划消失旧行保留/无表格/无小节/代办事项不触碰）。

## 扩展二（2026-09-24 午后）：今日总结「写入备注」按钮

用户需求：总结卡加「写入」按钮，点击把今日总结写进当天日记 `## 备注`——备注只有空序号占位（模板 `1. 2. 3.`）时取消序号写入；序号已有内容则追加到后面。

- **重复点击语义（Q1a）**：写入内容包在不可见 HTML 注释标记块里（`<!-- planflow:summary -->` … `<!-- /planflow:summary -->`），再点一次 = 原位替换块内内容——总结改完重按一下，备注永远同步最新总结，不堆重复。
- **编号规则（Q2b）**：备注小节里有已填内容的编号行（`N. 内容`）→ 删掉空序号占位行，总结各非空行**续接编号**（从块外最大号+1 起）；没有已填编号行 → 全部空序号删除，总结不加序号写入。编号只落非空行，总结内空行保留作段落分隔。
- **用户主动触发的反馈**：与自动投影不同，这里三种结果都 Notice——成功 / 日记不存在 / 无「## 备注」小节；总结为空也提示不写。
- **实现**：`remarksTransform` 纯函数（返回 null = 无小节）+ `writeSummaryToDiary`；按钮在总结卡底部按钮排（与「写复盘」并排 flex 各半）。配 14 项单测（情形A/B/幂等替换/编号重算/空行保留/无小节/普通文本追加）。

## 扩展三（2026-09-24 午后）：写复盘改弹窗 → 日记「# 当日复盘」

用户需求：「写复盘」从「创建/打开 `{date} 复盘.md` 文件」改为**弹窗输入**，内容写入当天日记——在「# 睡眠相关」和「# 随笔」之后**添加「# 当日复盘」标题**，内容放标题下。

- **插入位置（Q1a）**：新标题插在「# 随笔」小节结束处（睡眠相关 → 随笔 → 当日复盘 → 新闻联播…）；日记已有「# 当日复盘」小节则原位使用、不重复建。
- **重复写入（Q2a）**：替换当日复盘小节内容——复盘一天一份，改完重写即最新。
- **旧机制处置（Q3a）**：`{date} 复盘.md` 不再创建，`openOrCreateReview`/`loadReviewTemplate` 删除；设置页「复盘模板」板块原样保留（用户冻结区），仅不再被此按钮消费。复盘**打卡率统计不受影响**（基于每日笔记打卡行，`stats.ts`）；复盘计划行模板的 `→ [[{date} 复盘]]` 链接会悬空，待后续清理（另行确认）。
- **反馈**：用户主动触发，成功 / 日记不存在 / 无「# 随笔」锚点 三种结果都 Notice；内容为空提示不写。Ctrl+Enter 快捷提交。
- **实现**：`reviewTransform` 纯函数（null = 无「# 随笔」锚点）+ `writeReviewToDiary`；新增 `ReviewModal`（textarea，复用 planboard-modal 体系）。配 9 项单测（首写插入位置/替换幂等/标题唯一/首尾空行/无锚点/已有小节原位替换）。
- **扩展四（弹窗预填）**：弹窗打开时预填——日记已有当日复盘正文 → 预填正文（替换语义下防丢字）；否则预填复盘模板（`{root}/复盘模板.md` 文件 → `settings.reviewTemplate`，剥 frontmatter 与一级标题、`{date}` 占位替换，只留可填骨架）。`ReviewModal` 接受 prefill，光标定位末尾。
- **边界修正**：日记骨架章节均为一级标题，`# 当日复盘` 小节边界 = 下一个一级标题（`/^#\s/`），正文中的 `##` 子标题属于本小节——否则含子标题的模板内容重写时会被截断复制（第九轮实现的潜在 bug，回归测试捕获后修正）。

### 扩展五：备注写入去标记改版（- 列表样式 + 设置记录锚点）

- **问题**：扩展二的 HTML 注释标记块（planflow:summary 起止）在源码模式下可见，用户反馈观感差，要求「- 测试」列表样式。
- **改版**：弃标记；无编号语境各非空行加  前缀（空行保留）；编号语境维持续接编号（Q2b）。替换锚点改用设置新字段 （存上次写入块原文，data.json 随库同步，不进设置页 UI）：prev 块在「## 备注」小节内连续命中 → 原位替换；未命中/未提供 → 追加（空占位行删除、编号续接规则同前）。
- **迁移**：旧版标记块在 remarksTransform 中无条件摘除（含块内内容），首次写入即自愈。
- **已知取舍**：多端同时写总结时，summaryDiaryLast 可能过期 → 未命中走追加（不覆盖，安全侧）；用户手动改过日记里写入的行同理。
- **测试**：16 项单测（列表样式/无标记/占位删除/替换/编号续接/迁移清除/prev 未命中/无小节）。
